# Inventario Físico · Demo web

Frontend estático de demostración para revisión desde navegador. El backend usa exclusivamente el proyecto Supabase aislado dybdaadrosstijjflsfi.

Este repositorio no contiene base de datos, archivos XLS de la empresa, credenciales administrativas, claves de servicio ni secretos de la Edge Function. La clave sb_publishable_ del frontend es una clave pública diseñada para uso de navegador; el backend mantiene sus verificaciones de sesión y permisos.

Los conteos y operaciones requieren sesión emitida por el backend; el acceso no publica ni incorpora datos de inventario en el sitio estático.

Publicado gratis mediante GitHub Pages, sin dominio propio ni servicio de pago.
